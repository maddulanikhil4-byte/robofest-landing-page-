# ROBOFEST Landing Page

A beginner-friendly, responsive frontend concept for the ROBOTiX Club recruitment challenge at NIT Raipur.

## Files
- `index.html` — page structure and content
- `style.css` — layout, colors, responsive design, and animations
- `script.js` — mobile navigation, active menu links, scroll reveal, and information dialog

## Run locally
1. Download or unzip this folder.
2. Open `index.html` in Chrome, Firefox, or another browser.
3. An internet connection is needed for the Google Fonts and Unsplash images. The page itself does not need a backend.

## Publish with GitHub Pages
1. Create a new public repository on GitHub, for example `robofest-landing-page`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will look like `https://YOUR-USERNAME.github.io/robofest-landing-page/`.

## Theme and design
**Theme:** Futuristic robotics with a dark navy background and neon cyan accents.

The visual direction uses a glowing grid, technical labels, outlined buttons, cards, and subtle motion to suggest robotics and innovation. It is designed to remain readable and usable on both desktop and mobile screens.

## Technologies
- HTML5 for semantic page sections
- CSS3 for responsive layout, color system, hover effects, and animations
- Vanilla JavaScript for interactive navigation, scroll-based reveals, and the info dialog
